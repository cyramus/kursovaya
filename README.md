# ЧитайФест: Веб-сайт книжного фестиваля

## Описание проекта

Данный проект представляет собой одностраничный веб-сайт (SPA-подобный) для книжного фестиваля "ЧитайФест", проводимого в Тирасполе. Сайт предназначен для информирования посетителей о фестивале, его программе, участниках, карте мероприятий и планировщике визита. Проект разработан как курсовая работа по дисциплине "Веб-программирование" и демонстрирует современные подходы к созданию адаптивных и интерактивных веб-приложений.

### Основные цели проекта:
- Предоставить полную информацию о фестивале
- Обеспечить удобную навигацию по разделам
- Реализовать интерактивные элементы для улучшения пользовательского опыта
- Гарантировать адаптивность под различные устройства

## Глава 2. Проектирование веб-ресурса

### 2.1. Разработка структуры сайта

Структура сайта была спроектирована с учетом принципов пользовательского опыта (UX) и информационной архитектуры. Основной подход - разделение контента на логические разделы с возможностью быстрой навигации.

#### Основные страницы и разделы:
1. **Главная страница (index.html)** - входная точка сайта с обзором фестиваля
2. **О нас (about/)** - история, миссия, статистика, партнеры, FAQ
3. **Программа мероприятий (program/)** - расписание и описание событий
4. **Каталог участников (participants/)** - список авторов и издательств
5. **Карта фестиваля (map/)** - интерактивная карта площадок
6. **Планировщик визита (planner/)** - инструмент для планирования посещения

#### Навигационная структура:
- **Главное меню** - горизонтальная навигация в шапке сайта
- **Внутренняя навигация** - якорные ссылки для быстрого перехода к разделам
- **Breadcrumb навигация** - отсутствует, но предусмотрена возможность добавления

#### Файловая структура проекта:
```

│   └── blocks/

├── participants/              # Раздел участников
├── planner/                   # Планировщик визита
├── program/                   # Программа мероприятий
└── data/                      # JSON данные
    ├── events.json
    └── partisipants.json
```

### 2.2. Создание визуального дизайна

Визуальный дизайн разработан с учетом брендинга фестиваля и принципов современной веб-дизайна. Основные принципы:
- **Цветовая палитра**: Основные цвета - глубокий синий (#2c3e50) и акцентный оранжевый (#e67e22)
- **Типографика**: Использование шрифтов Playfair Display для заголовков и Crimson Text для основного текста
- **Адаптивность**: Mobile-first подход с breakpoints на 768px и 1024px

#### Дизайн-система:
- **Переменные CSS**: Все цвета, шрифты, отступы и размеры определены в variables.css
- **Компонентный подход**: Стили разбиты на блоки (cards, grids, buttons)
- **Визуальная иерархия**: Использование размеров шрифтов, весов и цветов для выделения важной информации

#### Ключевые визуальные элементы:
- **Герой-секция**: Полноэкранный баннер с призывом к действию
- **Карточки**: Единообразный дизайн для мероприятий, участников, партнеров
- **Галерея**: Сетка изображений с модальным просмотром
- **Формы**: Стилизованные элементы ввода для планировщика

## Глава 3. Реализация проекта

### 3.1. HTML-структура и семантическая разметка

Проект использует современный HTML5 с семантическими элементами для улучшения доступности и SEO.

#### Основные HTML-элементы:
- **`<header>`** - Шапка сайта с логотипом и навигацией
- **`<main>`** - Основной контент страницы
- **`<section>`** - Логические разделы контента
- **`<article>`** - Самостоятельные блоки контента (мероприятия, участники)
- **`<aside>`** - Дополнительная информация (боковые панели)
- **`<footer>`** - Подвал сайта с контактами

#### Семантическая структура главной страницы:
```html
<body>
    <header class="header" role="banner">
        <!-- Навигация и логотип -->
    </header>
    
    <main class="main-content">
        <section class="hero" id="hero">
            <!-- Герой-секция -->
        </section>
        
        <section class="events" id="events">
            <!-- Мероприятия -->
        </section>
        
        <section class="participants" id="participants">
            <!-- Участники -->
        </section>
        
        <section class="map-preview" id="map-preview">
            <!-- Карта -->
        </section>
    </main>
    
    <footer class="footer" role="contentinfo">
        <!-- Контакты -->
    </footer>
</body>
```

#### Доступность:
- Использование ARIA-атрибутов (role, aria-label, aria-expanded)
- Альтернативный текст для изображений
- Логическая последовательность табуляции
- Поддержка клавиатурной навигации

### 3.2. Стилизация с использованием CSS

#### Архитектура CSS:

##### Модальные окна:
```javascript
class Modal {
    constructor(modalElement) {
        this.modal = modalElement;
        this.overlay = modalElement.querySelector('.modal__overlay');
        this.closeBtn = modalElement.querySelector('.modal__close');
        this.init();
    }
    
    init() {
        this.bindEvents();
    }
    
    bindEvents() {
        this.overlay.addEventListener('click', this.close.bind(this));
        this.closeBtn.addEventListener('click', this.close.bind(this));
        document.addEventListener('keydown', this.handleKeydown.bind(this));
    }
    
    open() {
        this.modal.setAttribute('aria-hidden', 'false');
        document.body.style.overflow = 'hidden';
    }
    
    close() {
        this.modal.setAttribute('aria-hidden', 'true');
        document.body.style.overflow = '';
    }
}
```

## Установка и запуск

### Требования:
- Современный веб-браузер (Chrome 80+, Firefox 75+, Safari 13+)
- Локальный сервер для тестирования (опционально)

### Установка:
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/cyramus/kursovaya.git
   cd kursovaya
   ```

2. Откройте проект в VS Code или другом редакторе

3. Для локального сервера установите расширение Live Server в VS Code или используйте:
   ```bash
   npx serve .
   ```

4. Откройте `index.html` в браузере

### Структура файлов:
- `index.html` - Точка входа
- `main/` - Общие стили и скрипты
- `about/`, `map/`, `participants/`, `planner/`, `program/` - Разделы сайта
- `data/` - JSON данные
